# 6.7 更新日志

6.7 版本让画布比例以第二屏实际可用的显示区域为准，主窗口布局随第二屏比例自适应，并修复了播放中拖动进度和水平位置在双屏上不一致的问题。

## 6.7.0

### 以第二屏为核心的比例自适应

- 第二屏打开后会测量自己实际可用的显示区域，画布比例以实测尺寸为准；打开前先按显示器分辨率预估。刘海屏、系统面板、全屏没有铺满等情况下，第二屏不再留黑边，主窗口预览与第二屏保持一致。
- 主窗口布局随第二屏比例自适应：竖屏、方屏等窄比例输出时，控制栏自动移到右侧，让预览尽量高；横屏输出保持底部控制栏。窗口宽度小于 900 像素或处于全屏模式时始终使用底部控制栏。拖大底部控制栏不会触发切换，原来的底栏高度也会保留。
- 浏览进度条移到预览区边缘，不再遮挡竖屏等窄画布上的稿件。

### 修复

- 修复播放中拖动进度条无效：之前位置会被拉回拖动前，现在拖动时位置跟手，第二屏实时同步。
- 修复水平位置在主屏预览和第二屏上比例不一致：之前第二屏比主窗口宽时偏移会被放大（例如设为 10，预览偏 10%，第二屏偏 15%）。现在按画布宽度百分比计算，两边一致，数值显示由 `vw` 改为 `%`。
  - 之前在宽屏第二屏上设置过水平位置的，第二屏上的实际偏移会变小，变得与预览一致。

### 界面

- 第二屏的剩余字数指示器改为半透明，背景模糊减轻，压在稿件上时能透出下面的文字。
