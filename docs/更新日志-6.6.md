# 6.6 更新日志

6.6 版本起 Tauri 版成为主力维护的全平台版本，支持 Windows、macOS 和 Linux；Electron 版保留为 Windows 备用版本。

## 6.6.0

### 全平台支持

- Tauri 版新增 macOS 和 Linux 安装包：macOS 提供 Apple 芯片与 Intel 通用的 `.dmg`；Linux 提供 x86_64 与 ARM64 的 `.AppImage`、`.deb`、`.rpm`。
- Windows 新增 ARM64 安装包。
- macOS 上第二屏输出改用"简单全屏"：直接铺满目标显示器并保持置顶，不再切到独立的桌面空间（Space）。
- macOS 上按目标显示器自身的缩放比例定位第二屏窗口，修正 Retina 屏加外接屏混合缩放时的位置偏差。

### 修复

- 修复第二屏刚打开、收到主屏位置后又跳回顶部的问题。原因是页面加载后排队等待执行的布局恢复会用旧进度覆盖新位置；现在期间如果已有更新的定位，以新定位为准。
- 修复导入新稿件或清空稿件后，位置可能跳回导入前进度的问题。

### 工程

- 源码目录 `windows-tauri/` 改名为 `tauri/`。
- PowerShell 维护脚本改为跨平台的 `scripts/project.mjs`（`npm run check`、`npm run sync:version` 等），Windows、macOS、Linux 通用；版本检查新增 `Cargo.lock`。
- GitHub Actions 支持一键发版：在 Actions 页面填写版本号，即可自动同步版本、打标签、构建全平台安装包，并以更新日志作为 Release 说明发布。每个 PR 都会运行全平台构建。
