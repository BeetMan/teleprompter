# 6.5 更新日志

6.5 版本为 Tauri 版补上显示器热插拔处理，并整理输出窗口状态查询的代码结构。

## 6.5.0

### 显示器热插拔（Tauri 版）

- Tauri 版新增显示器配置监听：拔插显示器、增减屏幕、改分辨率时，第二屏输出和显示器选择器会及时更新，不再只依赖前端每 2 秒的轮询。之前 Tauri 版缺少这一处理（Electron 版早已通过原生显示器事件支持）。
- 输出显示器在提词过程中被拔掉时，自动收起第二屏并提示"输出显示器已断开"，主窗口重新获得焦点。
- 后端约 1.5 秒采样一次显示器指纹（位置 + 尺寸），变化时主动推送状态给前端；前端轮询保留作为兜底。

### 工程

- 重构 `inspect_output_status`：把原本混在查询里的副作用（隐藏断开的第二屏、清显示器 ID、聚焦主窗）抽到独立的 `reconcile_output_display`，查询函数变成"先协调再构建快照"的薄编排，行为不变，便于热插拔监听复用。
- 同步提交 `Cargo.lock`（包版本 6.4.0 → 6.4.4 → 6.5.0）。
