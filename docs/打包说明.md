# 打包说明

本文档说明如何构建 Tauri 版（Windows / macOS / Linux）和 Electron 版（仅 Windows）。正式发布包由 GitHub Actions 自动构建，本地打包主要用于自测。

## 环境要求

### 通用

- Node.js 20 LTS 或 22 LTS 与 npm
- Rust 稳定版工具链（仅 Tauri 版）

### 各平台系统依赖（Tauri 版）

- **Windows 10 / 11**：WebView2 Runtime（Windows 11 已内置）
- **macOS 10.15+**：Xcode Command Line Tools，执行 `xcode-select --install` 安装
- **Linux（Ubuntu 22.04+ / Debian 12+）**：

```bash
sudo apt-get install -y libwebkit2gtk-4.1-dev libappindicator3-dev librsvg2-dev patchelf
```

## Tauri 版打包

```bash
cd tauri
npm install
npm run build
```

`npm run build` 会按当前平台生成全部支持的安装包格式，也可以用 `--bundles` 只构建需要的格式：

| 平台 | 命令 | 输出目录 |
| --- | --- | --- |
| Windows | `npm run build -- --bundles nsis` | `tauri/src-tauri/target/release/bundle/nsis/` |
| macOS（当前芯片） | `npm run build -- --bundles app,dmg` | `tauri/src-tauri/target/release/bundle/dmg/` |
| macOS（通用二进制） | `npm run build -- --target universal-apple-darwin --bundles app,dmg` | `tauri/src-tauri/target/universal-apple-darwin/release/bundle/dmg/` |
| Linux | `npm run build -- --bundles deb,appimage` | `tauri/src-tauri/target/release/bundle/deb/`、`appimage/` |

构建 macOS 通用二进制前需要安装两个目标：

```bash
rustup target add aarch64-apple-darwin x86_64-apple-darwin
```

macOS 包使用 ad-hoc 签名（`signingIdentity: "-"`），未经过 Apple 公证。

图标位于 `tauri/src-tauri/icons/`。更换图标时准备一张至少 512×512 的方形 PNG，运行 `npx tauri icon <图片路径>` 重新生成，然后删除不需要的 `android/`、`ios/` 和 `Square*` 文件。

版本号位置：

```text
tauri/package.json
tauri/src-tauri/Cargo.toml
tauri/src-tauri/Cargo.lock
tauri/src-tauri/tauri.conf.json
```

## Electron 版打包（仅 Windows）

目录：

```text
windows-electron
```

命令：

```powershell
cd windows-electron
npm install
npm run dist:win -- --config.win.signAndEditExecutable=false
```

输出文件：

```text
windows-electron/dist/提词器 6.5.0.exe
windows-electron/dist/提词器 Setup 6.5.0.exe
```

版本号位置：

```text
windows-electron/package.json
windows-electron/index.html
```

`package.json` 使用完整版本号，例如 `6.5.0`。

`index.html` 中的 `app-version` 使用短版本号，例如 `6.1`。

## 版本号同步

Tauri 版和 Electron 版使用统一产品版本号。修改版本号时优先运行：

```bash
npm run sync:version -- 6.5.0
```

发布前可以运行：

```bash
npm run sync:frontend
npm run check:version
node scripts/project.mjs check-parity
```

或直接运行完整检查：

```bash
npm install
npm run check
```

脚本会同步：

- `VERSION`
- `tauri/package.json`
- `tauri/package-lock.json`
- `tauri/src-tauri/Cargo.toml`
- `tauri/src-tauri/Cargo.lock`
- `tauri/src-tauri/tauri.conf.json`
- `tauri/web/index.html`
- `windows-electron/package.json`
- `windows-electron/package-lock.json`
- `windows-electron/index.html`

## 打包前检查

- 稿件导入是否正常
- 第二屏输出是否正常
- 水平镜像和垂直镜像是否正常
- 第二屏是否能用 `Esc` 退出
- 播放、暂停、回到顶部、回到尾部是否正常
- `↑ / ↓` 快速滚动是否会同步到第二屏
- `← / →` 调速是否正常
- 黑底白字、白底黑字显示是否正常
